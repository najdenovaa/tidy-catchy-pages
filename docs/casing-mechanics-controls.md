# Этап 4: контрольные случаи F14/F17

Основание - стр. 2 исходного ТЗ: нагрузка на крюке с расстановкой центраторов, инклинометрией и кавернометрией (F14), центрация с кавернометрией и инклинометрией (F17). Проверки ниже являются воспроизводимыми математическими контролями ограниченной модели, а не промысловой приёмкой.

## Исправления F17

Прежний профиль боковой нагрузки использовал только абсолютную разность зенитов; автоподбор классифицировал зоны по 3D-кривизне, но интерполировал азимут напрямую. В результате поворот при постоянном зените не давал соответствующей дополнительной нагрузки, а переход 359°/1° мог интерполироваться через 180°.

Теперь ручной профиль, А/Б и автоподбор используют общую интерполяцию по кратчайшей дуге. Знаковые градиенты углов усредняются по физическому окну 30 м с обрезкой по концам колонны. DLS учитывает скалярное произведение пространственных касательных. Натяжение для центрации - интеграл осевого веса нижележащей части, а не её длина, умноженная на косинус местного угла. Для линейного изменения зенита интеграл cos(I) вычисляется аналитически. Плотность одинаковой жидкости внутри/снаружи задаёт плавучий вес. Ниже последнего замера продолжаются последние углы и TVD.

Боковая нагрузка на метр:

`q = hypot(w*sin(I) + T*dI/dMD, T*sin(I)*dAz/dMD)`.

Термы в плоскости набора складываются со знаком: при снижении угла возможно уменьшение нагрузки. Поворот по азимуту даёт вторую составляющую. Это баланс soft-string, а не решение пространственного контакта. [Университетский источник с балансом сил](https://repository.tudelft.nl/file/File_bceeecde-c5a3-4ee4-af33-59bdd2f674df), раздел 4.

Реакции/прогибы наследуют имеющуюся модель пружинных опор или шарнирных пролётов А/Б. Направление смещения, касание верхней/нижней стенки и перераспределение контактных реакций не решаются. Окно 30 м сглаживает короткие изменения кривизны. Номинальные сталь/стенка постоянны в этой модели центрации; погонная масса и геометрия секций F14 не объявляются перенесёнными в F17. Устаревшая эмпирика без центраторов и непаспортных изделий не становится подтверждённой данной поправкой.

## Исправления F14

Раньше геометрический проход оснастки проверялся в выбранных положениях башмака веника. Короткое сужение между этими положениями могло быть пропущено. Теперь каждое установленное изделие проверяется по всем интервалам на пути от устья до окончательной MD. Первая конфликтная глубина башмака находится из кинематики `shoeMD = stringLength - toolTargetMD + restrictionTopMD`; проверка трубы выполняется отдельно. Пружинное изделие проверяется по диаметру колец, жёсткое - по наружному диаметру. Деформация колец и продавливание через сужение не предполагаются. Совпадение диаметров считается отсутствием зазора.

Отдельный совместимый адаптер больше не возвращает `willRunFreely=true` при выявленном ограничении прохода либо превышении заданной грузоподъёмности. Отсутствие этих сигналов не гарантирует спуск: полная устойчивость, прихват и hard-string контакт не рассчитаны.

## Воспроизводимые контроли

Файл `src/lib/casing-mechanics-controls.test.ts`:

| Контроль | Независимое основание / критерий |
|---|---|
| F17, зенит 30°, поворот 30° на 120 м, MD 60 м | Аналитическая нагрузка из двух компонент; реакция на условном пролёте 12 м совпадает до 1e-9 кН; standoff уменьшается относительно прямой траектории |
| F17, набор 20→40° и снижение 40→20° | Натяжение отдельно интегрируется 6000 шагами по 0.01 м; реакция совпадает до 1e-7 кН |
| F17, компенсация веса и кривизны | При w=100 Н/м, I=30°, T=5000 Н и dI/dMD=-0.01 рад/м нормальная нагрузка равна нулю |
| F17, переход через север | Профиль/расстановка 359→1° совпадают с -1→1°; сравнение не требует побитного совпадения чисел с плавающей точкой |
| F17, линейный зенит 0→60° | Интеграл осевого веса равен wL*sin(pi/3)/(pi/3); продолжение TVD ниже последнего замера проверено отдельно |
| F14, набор/снижение/поворот | Обе ветви крюка сопоставлены с отдельным RK4-решением дифференциального баланса, шаг 0.05 м; относительное расхождение менее 1e-4 |
| F14, проход | Жёсткое изделие 230 мм не проходит через 200 мм; короткое сужение MD 31.1–31.3 м обнаруживается независимо от точек веника |

Исходная труба контрольных задач: 168.3×8.9 мм, сталь 7850 кг/м³, жидкость 1100 кг/м³; G=9.80665 м/с². Расстановка и паспорт в тесте синтетические и явно названы аналитическим контролем, не изделием изготовителя.

Сохраняются прежние проверки вертикали, прямого наклонного участка, фактического количества А/Б, qL⁴-прогиба, равновесия реакций, экспорта и отдельности отчётов. Новые ограничения выводятся в UI и выгрузках штатным путём. Независимая промысловая кривая, фактические измеренные профили, нелинейный контакт, направление прогиба и приёмка области применимости F14/F17 остаются открытыми. Наличие контрольных тестов не меняет статус этих пунктов на «полностью принято».
