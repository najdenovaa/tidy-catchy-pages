# Автоподбор полной программы

Выбранная рекомендация теперь содержит одну связанную программу: ступени всех жидкостей, рассчитанную центрацию, конкретные турбулизаторы из справочника, ведомость и запись результатов для отчёта. «Лучшее качество» ранжируется по существующему CQI; вытеснение остаётся отдельным показателем.

## Проход буферов

Целевая зона: пласты и 150 м выше кровли по TVD; если пласты не заданы, фактический интервал цементирования с явной подписью. Учитываются объёмы трубы и затрубья, последовательность жидкостей и моменты прибытия фронта/хвоста. Ступени поверхностной закачки меняются, когда буфер находится в нужной зоне, включая закачку последующих жидкостей.

Химический буфер проходит зону при 10 л/с ламинарно; тяжёлый — с переходным или турбулентным участком прохода на каждой контрольной глубине. Проверка использует нативные кадры гидравлического расчёта и фактический возврат из затрубья. Если условие не подтверждено, кандидат не предлагается. Учитываются ограничения затворения, давления, поглощений и времени загустевания.

При включённом подборе буферов применяются существующие стартовые рецептуры и пересчитываются объёмы. При выключенном состав, плотность и объём заданных буферов сохраняются. Ступени всё равно рассчитываются. Лабораторные свойства и смытие не выдумываются: CQI — расчётная оценка, не подтверждение 85% фактического смытия.

## Оснастка

Используются встроенные паспортные модели и последние версии пользовательской библиотеки. Добавлена категория «Турбулизатор» с геометрией и источником. Проверяются размер ОК, внутренний проход изделия, минимальный проход ствола/предыдущей колонны и известный температурный предел. Отсутствующий типоразмер не масштабируется и не заменяется выдуманной моделью.

Встроенные ЦТГП Нефтемаш 146/168/178/245 внесены отдельными каталожными записями по https://remoil.ru/products/2/32 (проверено 23.11.2026). Ранее предоставленный паспорт ЦТГП-178/210 сохранён отдельно. В противоречивой строке каталога 245 мм не используется указанное там значение ствола 215,9 мм. Неопубликованные размеры/силовые характеристики не объявляются паспортными: остаются явными допущениями существующей модели.

Центраторы расставляются по расчётному Standoff. Количество определяется фактическими точками, включая неполные трубы. Турбулизаторы размещаются по существующей модели затухания L90 с ограничением шага длиной трубы; совместное размещение проверяет перекрытие корпусов. Местные потери каждого турбулизатора входят в окончательную гидравлику. Модели, источники, версии и количества сохраняются в проекте и отчёте.

Поиск конечный и поэтапный: предварительная сетка расходов/центрации, затем лучшие кандидаты по качеству, запасу, времени и каждой расстановке проверяются в полном расчёте с подходящими турбулизаторами и расходами тяжёлого буфера. Глобальный оптимум не гарантируется.

## Применение

У каждой основной рекомендации одна кнопка «Применить». Она переносит полную программу и пересчитывает зависимые вкладки. Изменение исходных данных до применения делает результат устаревшим. Историческая запись автоподбора сохраняется; после ручного изменения требуется повторный расчёт. Отдельная диагностическая ветка старого сценария очистки остаётся совместимой с программным API без каталога; интерфейс использует полный подбор.

Проверки: сохранение/восстановление, размерная совместимость и отсутствие пересечений, версии библиотеки, проход буферов, выключенный подбор рецептуры, ведомость, DOCX и браузерное применение разных вариантов на компьютере и телефоне.
