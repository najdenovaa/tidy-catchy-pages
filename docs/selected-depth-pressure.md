# Давление и ЭЦП на выбранной глубине

13.11.2026. Прямые требования F15/F16 матрицы ТЗ; экспорт относится также к F10/F19. Пользовательская функция основной программы цементирования, не отдельный исследовательский стенд.

В «Анализ - Графики» задаются координата MD/TVD и глубина в пределах рассчитанной колонны. Кнопка применяет выбор к рассчитанному снимку программы и сохраняет запрос в проекте. Основные геометрия/жидкости/режимы при выборе точки не меняются. Для применения других изменённых исходных данных требуется обычный пересчёт программы.

При выборе TVD используется кусочно-линейная траектория рассчитанного снимка. Если TVD пересекается несколько раз или соответствует горизонтальному интервалу, программа требует явную MD; не выбирает первое пересечение. Экстраполяция за покрытие не допускается. Начало MD/TVD должно быть 0/0. Условный профиль по глубинам при отсутствии измеренной инклинометрии явно подписан. Восходящий участок делает наблюдение недоступным, поскольку унаследованная основная гидростатическая модель пока использует положительные приращения TVD.

Для каждого сохранённого кадра берётся фактическое FIFO-размещение жидкостей в затрубье, свойства соответствующих жидкостей, расход через башмак, общий профиль геометрии, реология, профиль standoff и калибровка трения. Гидростатика и трение от глубины до поверхности вычисляются теми же функциями, что в основном расчёте. Огибающие не интерполируются для получения временного ряда. На Стоп затрубное трение нулевое; насосный скачок посадки не переносится в затрубье. При U-tube расход в затрубье берётся из его рассчитанного состояния, а не только из подачи насоса.

ЭЦП = Pзатрубья / (0.00981 × TVD), г/см³. При TVD не выше 1e-6 м эквивалентная плотность не определяется; давление остаётся доступно. Отсутствующее значение не заменяется нулём.

Пластовое давление берётся только из заданных градиентов пластов, перекрывающих выбранную MD. Нормальный пластовый градиент не подставляется автоматически. ГРП: общий градиент применяется в открытом стволе, ограничения пластов - в их интервалах; при пересечении берётся минимальное заданное давление. Поглощение - из заданных пластов. Показанный предел - 95% меньшего из известных ГРП/поглощения, как в текущей карте давлений. Неизвестные ограничения показаны отсутствующими.

UI содержит два графика, числовую таблицу и выгрузки CSV/XLSX. XLSX сохраняет полный ряд без прореживания, обе координаты, единицы, известные давления и лист условий/ограничений. Word содержит запрос, разрешённые MD/TVD, источники границ, максимум, графики; полный ряд включается при выборе числовых данных графиков. Нерассчитанная точка подписана явно. Ключ результата и рисунков привязан к физическим данным и запросу; прежний ряд/рисунки исключаются после изменения глубины, трения или других расчётных входов. Справочная библиотечная ссылка и ведомость оборудования сами по себе гидравлику не меняют.

Ограничения: это основная квазистационарная модель и её плотности/временные кадры. Гидроудар, связанный теплообмен, P/T-плотность пены и пики между кадрами не добавлены. Наличие этой функции не означает полной приёмки гидравлики, пеноцементирования или всего ТЗ.

Проверки: совпадение с забойным и башмачным рядами во всех кадрах, гидростатический старт, отсутствие трения после Стоп, независимость основной операции от выбранной точки, горизонтальный участок без выдуманной ЭЦП, неоднозначная TVD, непокрытая траектория, неизвестные давления, калибровка трения, XLSX round-trip, устаревший Word/рисунки и независимый рендер отчёта.
