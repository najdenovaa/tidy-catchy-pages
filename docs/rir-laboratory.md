# Рецептура и лаборатория РИР

РИР теперь имеет собственную стартовую цементную рецептуру и лабораторный блок. Рецептуры мостов не используются. Для микроцемента и смол сохранены прежние ориентировочные модели с отдельным вводом лабораторного факта.

- Расход рассчитывается по абсолютным объёмам компонентов. Редактируются фактические марки, партии, массовые части и SG. Показываются кг/м³, граммы лабораторной пробы и кг на операцию с запасом.
- Стартовые дозировки ПЦТ являются начальной лабораторной пробой, не аттестованной рецептурой. Для ПЦТ не выдумываются кривые загустевания и прочности.
- Факт: плотность, ПВ/вязкость, ДНС, загустевание до 70 Bc либо гелеобразование, водоотдача, свободная вода, седиментация, прочность с возрастом, совместимость, щелевой тест с шириной, перепадом, прошедшим объёмом и временем.
- Требования водоотдачи, прочности и стабильности задаются программой испытаний. Отсутствующие данные не считаются положительным результатом.
- Привязка требует идентификации лаборатории, исполнителя, даты, протокола и партий всех компонентов, совпадения BHCT/BHST с расчётом в пределах 2 °C. Это технический допуск для отслеживания актуальности, не отраслевой критерий приёмки.
- Перенос измеренных плотности, ПВ/вязкости и времени жизни выполняется отдельной кнопкой. Плотность поступает в гидростатику и окно давлений; реология и время жизни поступают в моделирование. ПВ суспензии лишь приближает эффективную вязкость канала. Модель не рассчитывает фактическую фильтрационную корку, форму трещины и подтверждённую изоляцию.
- Изменение рецептуры, партий, условий либо факта отменяет привязку/перенос. Изменение температур скважины также прекращает применение вне допуска. Для каждого состава и технологии сохраняется отдельная проба в локальном проекте РИР.
- Для двухфазной системы требуется отдельная проба каждого компонента; однородный протокол к двум фазам не применяется.
- Word лаборатории экспортирует рецептуру и введённый факт. Полная программа РИР также включает лабораторный раздел. Формат документа общий, расчётные данные мостов не импортируются.
- Единичные значения не превращаются в вымышленные измеренные кривые. Щелевой тест показывает проходимость в заданной лабораторной щели, не определяет неизвестное раскрытие скважинной трещины.

Локальная среда исполнения в этой сессии недоступна. Проверка выполняется GitHub Actions: TypeScript, регрессионные тесты РИР, новые тесты лабораторной модели и интерфейса, production build. Интерактивная проверка браузером не выполнялась.
