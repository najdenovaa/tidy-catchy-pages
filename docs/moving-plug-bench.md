# Движущийся герметичный поршень: двухкамерный проверочный стенд

Это самостоятельная модель механического ядра, не прогноз посадки в проекте скважины. Включается отдельно в исходных данных; эталонный пример загружается явной кнопкой. Геометрия и свойства независимы от скважины. В «Анализ - Закачка» запуск выполняется вручную в Worker с отменой и сбросом результата при изменении параметров. В Word есть отдельный выбираемый пункт, по умолчанию выключенный и требующий явной галочки, с исходными параметрами, балансом, временем события и двумя графиками. Иллюстрации имеют полный ключ случая и исключаются при изменении параметров.

## Постановка

Горизонтальная жёсткая труба постоянного диаметра D и длины L. Герметичный поршень нулевой толщины разделяет две однородные изотермические камеры. Начальное положение x0 > 0, упор xs < L, поэтому обе вместимости положительны: Vb = A x, Va = A (L-x), A = pi D²/4. Объём жидкости через поршень не проходит; суммарная вместимость камер сохраняется точно.

Плотности заданы при 0 МПа избыточного давления. Для каждой камеры rho(p) = rho0 exp(p/K), K постоянно. Начальное давление обеих камер равно заданному давлению выхода. Подача сзади задаётся объёмом при 0 МПа: m_in/dt = rho0,b Q_ref. Выход впереди - идеальный резервуар при pout, соединённый линейным сопротивлением R. При R > 0 объёмный расход на стороне камеры Qout = max(0,(pa-pout)/R), массовый расход rho_a(pa) Qout. При R = 0 давление pa = pout задаётся как алгебраическое условие, отток определяется балансом.

До упора поршень может двигаться только вперёд. Без движения pb-pa <= dp0. При движении pb-pa = dp0 + C v. dp0 - заданный постоянный перепад трения скольжения и порог сдвига; C - заданное вязкое сопротивление. Инерция отсутствует. Это не паспортная характеристика реальной пробки и не модель её массы, деформации, утечек, среза или обратного хода. Гравитация, распределённые градиенты давления и упругость трубы не включены.

## Численная схема

На шаге dt неизвестны новое положение x и давления. Масса сзади mb_new = mb_old + rho0,b Q_ref dt; pb = Kb log(mb_new/(rho0,b A x)). Впереди решается неявный баланс rho0,a exp(pa/Ka) [Va + dt max(0,(pa-pout)/R)] = ma_old. Давление pa находится монотонной бисекцией. Затем монотонной бисекцией по x решается силовое условие с v = (x-x_old)/dt. При недостижении порога x остаётся прежним, жидкость сзади сжимается.

Если свободное движение пересекло бы упор, отдельная бисекция по dt локализует достижение xs. Шаг заканчивается на этом событии, оставшееся время продолжается следующим шагом уже при фиксированном x = xs. Время посадки не назначается и не определяется по скачку давления. После упора уравнение свободного движения исключается: удержание обеспечивается упором/статическим трением. Нулевая силовая невязка в этом режиме не означает нулевую реакцию; её разложение отдельно не вычисляется. Скорость в сохранённой строке - средняя на принятом интервале, флаг посадки относится к его концу.

Впереди отток вычисляется из закона сопротивления (при R > 0), а оставшаяся масса - из EOS и вместимости; их невязка проверяется независимо. Для R = 0 отток определяется алгебраическим балансом. Контролируется полная масса камер, принятый шаг не меняет входное состояние. Недопустимые давления (p < 0 или p/K > 0.1), несходимость или более 1000 назначенных шагов останавливают стенд с сохранением принятой части. Ограничение EOS - программная область принятой модели, не допустимое рабочее давление.

## Независимые контрольные случаи

Для R = C = dp0 = 0 до упора pa = pb = pout. Аналитическое время xs: t_land = A (xs-x0) exp(pout/Kb)/Q_ref. После посадки pb = Kb log[exp(pout/Kb) + Q_ref (t-t_land)/(A xs)]. Проверены оба выражения и независимость события от шага времени.

Дополнительно: удержание ниже порога; неизменность старого состояния; массы обеих камер и силовой баланс при сопротивлениях; задержка посадки из-за сопротивлений; уменьшение временной ошибки относительно мелкого шага; остановка на EOS без потери принятого состояния; отмена и устаревший Worker; выбранный/невыбранный раздел Word, исключение устаревших рисунков и независимый рендер графиков.

## Что ещё требуется

Для подключения к скважине нужна пространственная модель с подвижной непроницаемой границей, согласованными потоками относительно сетки, неоднородными жидкостями, геометрией/траекторией, клапанами и упругостью. Двухкамерный стенд не заменяет эту работу. Динамика удара, реальное трение и деформация пробки требуют измеренных характеристик и промысловой валидации. Тепловая связность остаётся отдельной задачей.
